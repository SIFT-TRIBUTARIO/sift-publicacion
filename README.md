# SIFT · canal de actualizaciones

Este repositorio publica las versiones de SIFT que los equipos autorizados descargan automáticamente.

- `sift/version.json`: número de versión, fecha y notas de la publicación.
- `sift/carga-<versión>.txt`: el programa, **cifrado (AES-256-GCM)**. Solo se abre desde un archivo SIFT instalado y con una cuenta válida.

Aquí no hay código legible ni datos de contribuyentes: las bases de SINFA se procesan únicamente en el navegador de cada funcionario.
